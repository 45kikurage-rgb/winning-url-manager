当選URL管理・共有送信版

このZIPは、一時箱・全ファイル重複確認・コピー制限に対応しています。
必ず winning-url-api を先にデプロイしてから更新してください。

GitHub の winning-url-manager へ以下6ファイルを上書きアップロード:
- index.html
- share.html
- manifest.webmanifest
- sw.js
- icon-any.png
- icon-maskable.png

Cloudflare は GitHub 更新後に自動デプロイされます。

Android:
1. Chromeで https://winning-url-manager.45kikurage.workers.dev を開く
2. 既存のホーム画面ショートカット/PWAがある場合は一度削除
3. Chromeメニューから「アプリをインストール」または「ホーム画面に追加」
4. 対象ページで「共有」
5. 共有先に「URL送信」または「当選URL管理」が表示されたら選択
6. share.html が起動し、自動的に現在選択中の保存先へ送信

NOVAバックアップ配置照合:
1. GitHub更新後、既存PWAを一度削除して再インストール
2. Nova Launcherの「バックアップと復元」でバックアップを作成
3. バックアップの共有先に「URL送信」または「当選URL管理」を選択
4. .novabackupは当選URLへ送られず、管理画面の「NOVAバックアップ照合」カードへ端末内保存
5. 全端末分をメイン端末へ集め、まとめて選択する
6. 端末名は端末01・端末02…と自動設定。LINE上限は1〜150の任意数（126・127など）を入力可能
7. 「全端末を解析・照合」を押す
8. 1ページ30位置・最大5ページ（1〜150）のアプリID一致状況を確認
9. 必要に応じて「照合表CSV」または「AI確認用JSON」を出力
10. 最初からやり直す場合は「全NOVAデータ削除」を押す

NOVAバックアップと解析結果はサーバーへ送信せず、このPWAのIndexedDBへ保存します。
バックアップの書き換え・Novaへの復元は行いません。

新規URLは一時箱へ受付されます。
管理画面の「全ファイル重複チェック」または毎日6:30・22:00の自動確認後、
ユニークURLだけが継続箱、収益、コピー対象へ反映されます。
